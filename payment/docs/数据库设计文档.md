## 3. 表结构详细说明

### 3.1 users（统一用户表）

核心认证表，所有角色（管理员、教师、学生、家长）共享此表进行登录认证。

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INT | PK, AUTO_INCREMENT | 用户唯一标识 |
| username | VARCHAR(50) | UNIQUE, NULLABLE | Web 登录用户名（微信用户可为空） |
| passwordHash | VARCHAR(255) | NULLABLE | bcrypt 哈希密码（微信用户可为空） |
| role | VARCHAR(20) | NOT NULL | 角色：admin / teacher / student / parent |
| wechatOpenid | VARCHAR(100) | UNIQUE, NULLABLE | 微信 OpenID |
| wechatUnionid | VARCHAR(100) | NULLABLE | 微信 UnionID |
| name | VARCHAR(50) | NOT NULL | 显示名称 |
| phone | VARCHAR(20) | NULLABLE | 手机号 |
| avatarUrl | VARCHAR(255) | NULLABLE | 头像 URL |
| status | VARCHAR(20) | DEFAULT 'active' | 账户状态：active / disabled |
| createdAt | DATETIME | DEFAULT NOW() | 创建时间 |
| updatedAt | DATETIME | ON UPDATE | 更新时间 |

**索引**: `idx_users_role`, `idx_users_phone`

---

### 3.2 students（学生表）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INT | PK, AUTO_INCREMENT | 学生唯一标识 |
| userId | INT | UNIQUE, FK → users.id | 关联登录账号（可为空） |
| studentNo | VARCHAR(20) | UNIQUE, NOT NULL | 学号（Excel 导入关键字段） |
| name | VARCHAR(50) | NOT NULL | 姓名 |
| gender | VARCHAR(10) | NULLABLE | 性别：male / female |
| birthDate | DATETIME | NULLABLE | 出生日期 |
| idCard | VARCHAR(255) | NULLABLE | 身份证号（AES 加密存储） |
| address | VARCHAR(255) | NULLABLE | 家庭地址 |
| nativePlace | VARCHAR(100) | NULLABLE | 籍贯 |
| hobbies | VARCHAR(255) | NULLABLE | 兴趣爱好 |
| photoUrl | VARCHAR(255) | NULLABLE | 照片 COS URL |
| classId | INT | FK → classes.id | 所属班级 |
| dormitoryId | INT | FK → dormitory_rooms.id | 所属宿舍（可为空） |
| enrollmentDate | DATETIME | NULLABLE | 入学日期 |
| status | VARCHAR(20) | DEFAULT 'active' | active / transferred / graduated / withdrawn |
| deletedAt | DATETIME | NULLABLE | 软删除标记 |
| createdAt | DATETIME | DEFAULT NOW() | 创建时间 |
| updatedAt | DATETIME | ON UPDATE | 更新时间 |

**索引**: `idx_students_studentNo`, `idx_students_classId`

## 4. 隐私与数据保护策略

| 敏感字段 | 保护策略 | 实施位置 |
|---------|---------|---------|
| passwordHash | bcrypt 加盐哈希 | 注册/登录 Service 层 |
| idCard (身份证号) | AES-256 加密存储 | Repository 层存取时加解密 |
| phone (手机号) | 非管理员 API 返回中间4位星号（如 138****1234） | Controller 层 |
| 数据所有权 | 学生仅见自己，家长仅见孩子 | ownershipMiddleware |
