# 中学学生管理系统 — 部署手册

## 1. 系统要求

### 1.1 服务器配置

| 项目 | 最低配置 | 推荐配置 |
|------|---------|---------|
| CPU | 2 核 | 4 核 |
| 内存 | 4 GB | 8 GB |
| 磁盘 | 40 GB SSD | 80 GB SSD |
| 操作系统 | CentOS 7+ / Ubuntu 20.04+ | Ubuntu 22.04 LTS |
| 带宽 | 3 Mbps | 5 Mbps+ |

### 1.2 依赖软件

| 软件 | 版本 | 用途 |
|------|------|------|
| Node.js | 18.x LTS | 后端运行时 |
| pnpm | 8.x+ | 包管理器 |
| MySQL | 8.0 | 数据库 |
| Nginx | 1.24+ | 反向代理 + 静态资源 |
| PM2 | 5.x | 进程管理 |
| Git | 2.x | 代码拉取 |

## 2. 开发环境搭建

### 2.1 克隆项目

```bash
git clone https://github.com/cqwfy/school.git
cd school
```

### 2.2 安装依赖

```bash
# 安装 pnpm（如果尚未安装）
npm install -g pnpm

# 安装项目依赖
pnpm install
```

### 2.3 启动 MySQL

```bash
# 使用 Docker
docker compose up -d

# 或连接已有 MySQL 实例
# 确保创建好 school_db 数据库
```

### 2.4 环境变量配置

```bash
# 复制环境变量模板
cp .env.example .env

# 编辑 .env 文件
vim .env
```

**必需配置项**:
```bash
DATABASE_URL=mysql://root:password@localhost:3306/school_db
JWT_SECRET=your-64-char-random-secret-string-here
JWT_REFRESH_SECRET=your-64-char-refresh-secret-string-here

# 微信小程序配置（可选，开发阶段可不填）
WECHAT_APP_ID=wxXXXXXXXX
WECHAT_APP_SECRET=XXXXXXXX

# COS 图片存储（可选，开发阶段可不填）
COS_SECRET_ID=XXXXXXXX
COS_SECRET_KEY=XXXXXXXX
COS_BUCKET=school-assets-xxx
COS_REGION=ap-guangzhou
```

### 2.5 初始化数据库

```bash
# 运行数据库迁移
pnpm db:migrate

# 填充种子数据
pnpm db:seed
```

### 2.6 启动开发服务

```bash
# 终端 1：启动后端 API 服务 (http://localhost:3000)
pnpm dev

# 终端 2：启动管理后台 (http://localhost:5173)
pnpm dev:admin

# 可选：Prisma Studio 查看数据库 (http://localhost:5555)
pnpm db:studio
```

## 3. 生产环境部署

### 3.1 服务器初始化

```bash
# 更新系统
sudo apt update && sudo apt upgrade -y

# 安装 Node.js 18
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt install -y nodejs

# 安装 pnpm
npm install -g pnpm pm2

# 安装 Nginx
sudo apt install -y nginx

# 创建应用目录
sudo mkdir -p /srv/sms
sudo chown $USER:$USER /srv/sms
```

### 3.2 构建项目

```bash
# 在本地机器上构建
pnpm build

# 构建产物：
# packages/shared/dist/        - 共享类型
# packages/server/dist/        - 后端 (esbuild 打包)
# packages/admin/dist/         - 管理后台 (Vite 打包)
```

### 3.3 上传到服务器

```bash
# 方式 1：使用部署脚本
SERVER_HOST=8.160.165.176 SERVER_USER=root bash scripts/deploy.sh

# 方式 2：手动 rsync
rsync -avz --progress \
  packages/server/dist/ \
  packages/server/prisma/ \
  packages/server/package.json \
  packages/server/ecosystem.config.js \
  root@8.160.165.176:/srv/sms/

rsync -avz --progress \
  packages/admin/dist/ \
  root@8.160.165.176:/srv/sms/admin-dist/
```

### 3.4 服务器配置

```bash
# SSH 登录服务器
ssh root@8.160.165.176

# 进入应用目录
cd /srv/sms

# 安装生产依赖
npm install --production

# 生成 Prisma Client
npx prisma generate

# 运行数据库迁移
npx prisma migrate deploy

# 创建环境变量文件
cat > .env << 'EOF'
NODE_ENV=production
PORT=3000
DATABASE_URL=mysql://root:password@localhost:3306/school_db
JWT_SECRET=your-production-jwt-secret
JWT_REFRESH_SECRET=your-production-refresh-secret
WECHAT_APP_ID=wx1bb10927f9d2da2d
WECHAT_APP_SECRET=your-app-secret
COS_SECRET_ID=your-cos-secret-id
COS_SECRET_KEY=your-cos-secret-key
COS_BUCKET=school-assets-xxx
COS_REGION=ap-guangzhou
CORS_ORIGIN=https://your-domain.com
EOF
```

### 3.5 启动 PM2

```bash
# 启动应用（cluster 模式，自动根据 CPU 核数分配实例）
pm2 start ecosystem.config.js

# 设置开机自启
pm2 save
pm2 startup

# 常用 PM2 命令
pm2 list              # 查看进程列表
pm2 logs sms-api      # 查看日志
pm2 reload sms-api    # 优雅重启
pm2 restart sms-api   # 硬重启
pm2 monit             # 实时监控
```

### 3.6 配置 Nginx

```bash
# 复制配置文件
sudo cp scripts/nginx.conf /etc/nginx/sites-available/sms

# 编辑配置，替换域名和 SSL 路径
sudo vim /etc/nginx/sites-available/sms

# 启用站点
sudo ln -s /etc/nginx/sites-available/sms /etc/nginx/sites-enabled/

# 测试配置
sudo nginx -t

# 重启 Nginx
sudo systemctl restart nginx
```

**Nginx 配置模板**:
```nginx
server {
    listen 80;
    server_name your-domain.com;

    client_max_body_size 10m;

    # API 反向代理
    location /api/ {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # 上传文件代理
    location /uploads/ {
        proxy_pass http://127.0.0.1:3000;
    }

    # Web 管理后台（SPA）
    location / {
        proxy_pass http://127.0.0.1:3000;
    }
}
```

### 3.7 HTTPS 配置（推荐）

```bash
# 使用 Certbot 获取免费 SSL 证书
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d your-domain.com

# 证书会自动续期
```

## 4. 微信小程序配置

### 4.1 微信公众平台设置

1. 登录 [微信公众平台](https://mp.weixin.qq.com/)
2. 进入 "开发管理" → "开发设置"
3. 配置服务器域名（request 合法域名）：
   - `https://your-domain.com`
4. 获取 AppID 和 AppSecret
5. 将 AppSecret 配置到服务器 `.env` 中

### 4.2 小程序上传

1. 在微信开发者工具中打开 `packages/miniprogram`
2. 修改 `utils/api.js` 中的 `BASE_URL` 为生产域名：
   ```js
   const BASE_URL = "https://your-domain.com/api/v1";
   ```
3. 点击 "上传" 按钮提交代码
4. 在微信公众平台提交审核

## 5. MySQL 数据库管理

### 5.1 备份数据库

```bash
# 手动备份
mysqldump -u root -p school_db > backup_$(date +%Y%m%d).sql

# 定时备份（crontab）
0 2 * * * mysqldump -u root -p'password' school_db | gzip > /backup/school_$(date +\%Y\%m\%d).sql.gz
```

### 5.2 恢复数据库

```bash
mysql -u root -p school_db < backup_20260513.sql
```

## 8. 故障排查

### 8.1 常见问题

| 问题 | 检查点 |
|------|--------|
| API 502/503 | PM2 进程状态：`pm2 list`；查看错误日志 |
| 数据库连接失败 | `.env` 中 DATABASE_URL 是否正确；MySQL 是否运行：`systemctl status mysql` |
| 静态资源 404 | admin-dist 路径是否正确；Nginx 配置 |
| 微信登录失败 | 服务器时间是否同步；AppSecret 是否正确 |
| CORS 错误 | CORS_ORIGIN 是否包含前端域名 |
| 上传失败 | COS 配置是否正确；磁盘空间是否充足 |

### 8.2 重启流程

```bash
# 1. 拉取最新代码
cd /srv/sms && git pull

# 2. 重新构建（本地或服务器）
pnpm build

# 3. 运行迁移（如有变更）
npx prisma migrate deploy

# 4. 重启服务
pm2 reload sms-api
```
