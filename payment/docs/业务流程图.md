## 2. 用户认证流程

### 2.1 Web 管理后台登录

```mermaid
sequenceDiagram
    participant U as 用户
    participant WA as Web 管理后台
    participant API as Express API
    participant DB as MySQL

    U->>WA: 输入用户名+密码
    WA->>API: POST /auth/login
    API->>DB: 查询用户
    DB-->>API: 返回用户信息
    API->>API: bcrypt 验证密码
    API->>API: 生成 accessToken + refreshToken
    API-->>WA: 返回 tokens + user
    WA->>WA: 存储 token 到 zustand
    WA->>WA: 按角色跳转对应首页
```

### 2.2 微信小程序登录

```mermaid
sequenceDiagram
    participant U as 学生/家长
    participant MP as 微信小程序
    participant WX as 微信服务器
    participant API as Express API
    participant DB as MySQL

    U->>MP: 点击"微信一键登录"
    MP->>WX: wx.login() 获取 code
    WX-->>MP: 返回 code
    MP->>API: POST /auth/wechat-login { code }
    API->>WX: jscode2session (code→openid)
    WX-->>API: openid
    API->>DB: 查询 openid 是否已绑定

    alt 已绑定用户
        API-->>MP: 返回 tokens + user
        MP->>MP: 跳转首页
    else 新用户
        API-->>MP: isNewUser=true + tempToken
        MP->>MP: 显示绑定页面
        U->>MP: 选择绑定类型 + 输入绑定值
        MP->>API: POST /auth/bind { tempToken, bindType, bindValue }
        API->>DB: 验证绑定值 + 关联 openid
        API-->>MP: 返回 tokens + user
        MP->>MP: 跳转首页
    end
```

## 3. 学生管理流程

### 3.1 学生信息维护

```mermaid
flowchart LR
    A[管理员/教师登录] --> B{操作类型}
    B -->|新增| C[填写学生信息表单]
    B -->|编辑| D[搜索/筛选学生]
    B -->|删除| D
    B -->|导入| E[上传 Excel 文件]

    C --> C1[上传照片 (可选)]
    C1 --> C2[提交创建]
    C2 --> C3[(数据库写入)]

    D --> D1[选择目标学生]
    D1 --> D2{操作}
    D2 -->|编辑| D3[修改信息 → 保存]
    D2 -->|删除| D4[软删除 (deletedAt)]

    E --> E1[服务端校验]
    E1 --> E2{校验结果}
    E2 -->|通过| E3[逐行写入]
    E2 -->|失败| E4[返回错误明细]
```

### 3.2 Excel 批量导入流程

```mermaid
sequenceDiagram
    participant T as 教师
    participant WA as Web 后台
    participant API as API
    participant DB as MySQL

    T->>WA: 下载导入模板
    T->>T: 填写学生数据
    T->>WA: 上传 Excel 文件
    WA->>API: POST /students/import (multipart)
    API->>API: exceljs 解析文件
    API->>API: Zod 逐行校验

    loop 每一行数据
        API->>DB: 检查学号是否重复
        alt 不重复
            API->>DB: INSERT 学生记录
        else 重复
            API->>API: 记录失败行
        end
    end

    API-->>WA: 返回导入结果 { success, failed, errors }
    WA->>T: 显示导入统计
```

## 4. 成绩管理流程

### 4.1 成绩录入 → 发布流程

```mermaid
flowchart TD
    A[教师] --> B[创建/选择考试]
    B --> C[选择课程]
    C --> D[选择班级]
    D --> E[批量录入成绩表格]
    E --> F{成绩格式校验}
    F -->|不通过| E
    F -->|通过| G[(保存到 grades 表<br/>状态: 未发布)]
    G --> H[教师点击发布]
    H --> I[计算班级排名]
    I --> J[计算年级排名]
    J --> K[更新 isPublished=true]
    K --> L[学生端可查看]
```

### 4.2 学生查成绩流程

```mermaid
sequenceDiagram
    participant S as 学生
    participant MP as 小程序
    participant API as API
    participant DB as MySQL

    S->>MP: 进入成绩页面
    MP->>API: GET /grades/my (自动带上 token)
    API->>API: 解析 token 获取 studentId
    API->>DB: 查询该学生的成绩<br/>(仅 isPublished=true)
    DB-->>API: 返回成绩列表
    API->>API: 按考试分组
    API-->>MP: 返回分组后的成绩
    MP->>S: 显示各科成绩+排名
```

## 5. 考勤与请假流程

### 5.1 考勤标记流程

```mermaid
flowchart LR
    A[教师] --> B[选择日期]
    B --> C[选择班级]
    C --> D[加载班级学生列表]
    D --> E[逐学生选择考勤状态]
    E --> F[批量提交]
    F --> G[(写入 attendance 表)]
    G --> H[标记完成]
```

### 5.2 请假申请与审批流程

```mermaid
sequenceDiagram
    participant S as 学生/家长
    participant MP as 小程序
    participant API as API
    participant T as 教师/管理员
    participant WA as Web 后台

    S->>MP: 填写请假申请
    MP->>API: POST /attendance/leave-requests
    API->>API: 校验日期范围
    API->>DB: 创建请假记录 (status=pending)

    T->>WA: 进入请假审批页面
    WA->>API: GET /attendance/leave-requests
    API-->>WA: 返回待审批列表

    T->>WA: 点击同意/拒绝
    WA->>API: PUT /leave-requests/:id/approve

    alt 同意
        API->>DB: 更新 status=approved
        API->>DB: 自动创建考勤记录 (sick_leave/personal_leave)
    else 拒绝
        API->>DB: 更新 status=rejected
    end

    S->>MP: 刷新查看审批结果
```

## 6. 费用管理流程

```mermaid
flowchart TD
    A[管理员] --> B[创建费用项目]
    B --> C[设置金额/年级/学期/截止日期]
    C --> D[一键生成缴费记录]
    D --> E[为全年级学生创建 payment 记录]

    F[学生/家长] --> G[小程序查看缴费列表]
    G --> H{缴费方式}

    H -->|线下缴费| I[学生线下交费给学校]
    I --> J[管理员在后台标记已缴费]

    H -->|线上缴费| K[小程序内微信支付]
    K --> L[微信支付回调]
    L --> M[自动更新 payment 状态]

    J --> N[(payment 状态更新为 paid)]
    M --> N
```

## 8. 宿舍分配流程

```mermaid
flowchart TD

    C --> D[创建房间]

    J --> K{检查容量}
```
