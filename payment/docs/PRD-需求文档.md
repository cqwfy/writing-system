## 1. 产品概述

### 1.1 产品定位

中学学生管理系统是一套面向初级中学的综合性数字化管理平台，覆盖学生信息管理、教务管理、考勤管理、成绩管理、费用管理、通知公告、宿舍管理和奖惩记录等核心业务场景。

### 1.2 目标用户

| 角色 | 人数估算 | 使用终端 | 核心诉求 |
|------|---------|---------|---------|
| 管理员 | 2-3 人 | Web 管理后台 | 全校数据管理、系统配置、统计分析 |
| 教师 | ~30 人 | Web 管理后台 | 班级管理、成绩录入、考勤标记、通知发布 |
| 学生 | ~500 人 | 微信小程序 | 查成绩、看考勤、缴费、请假 |
| 家长 | ~1000 人 | 微信小程序 | 查看孩子成绩、考勤、缴费情况 |

### 1.3 技术栈概览

| 层次 | 技术选型 |
|------|---------|
| 后端框架 | Node.js + Express + TypeScript |
| 数据库 | MySQL 8.0 + Prisma ORM |
| Web 管理后台 | React 18 + Ant Design 5 + ProComponents |
| 微信小程序 | 原生微信小程序 (TypeScript) |
| 共享层 | pnpm Monorepo + 共享类型包 |
| 文件存储 | 腾讯云 COS |
| 支付 | 微信支付 (V3 API) |
| 部署 | 腾讯云 CVM + PM2 + Nginx |

## 2. 功能需求

### 2.1 认证与权限 (P0)

#### 2.1.1 双通道登录

**Web 管理后台登录**
- 用户名 + 密码登录
- JWT 双 Token 机制：accessToken (2h) + refreshToken (7d)
- 登录后按角色路由到对应界面

**微信小程序登录**
- 微信一键登录：`wx.login()` 获取 code → 后端换取 openid
- 新用户绑定流程：选择绑定类型（学号/手机号）→ 输入绑定值 → 完成绑定
- 已绑定用户直接进入首页
- 支持跳过绑定（访客模式）

#### 2.1.2 权限控制 (RBAC)

| 权限 | admin | teacher | student | parent |
|------|-------|---------|---------|--------|
| 管理学生/教师 | ✅ | ❌ | ❌ | ❌ |
| 班级/课程/课表管理 | ✅ | ❌ | ❌ | ❌ |
| 成绩录入 | ✅ | ✅ | ❌ | ❌ |
| 成绩查看 | ✅ | ✅ | ✅ (自己) | ✅ (孩子) |
| 考勤标记 | ✅ | ✅ | ❌ | ❌ |
| 考勤查看 | ✅ | ✅ | ✅ (自己) | ✅ (孩子) |
| 请假审批 | ✅ | ✅ | ❌ | ❌ |
| 费用管理 | ✅ | ❌ | ❌ | ❌ |
| 缴费查看 | ✅ | ✅ | ✅ (自己) | ✅ (孩子) |
| 通知发布 | ✅ | ✅ | ❌ | ❌ |
| 通知查看 | ✅ | ✅ | ✅ | ✅ |
| 宿舍管理 | ✅ | ❌ | ❌ | ❌ |
| 数据导出 | ✅ | ✅ | ❌ | ❌ |

### 2.2 学生管理 (P0)

#### 2.2.1 学生信息 CRUD
- 基本信息：姓名、学号、性别、出生日期、身份证号、地址、籍贯、兴趣爱好
- 学籍信息：班级、入学日期、学籍状态（在读/转学/毕业/退学）
- 照片管理：上传 → 自动裁剪 + WebP 转换 → COS 存储
- 身份证号 AES 加密存储，API 仅返回后 4 位

#### 2.2.2 Excel 批量导入/导出
- **导入**：模板下载 → 填写 → 上传 → 校验 → 逐行导入，返回成功/失败明细
- **导出**：筛选条件（班级、年级、状态）→ 导出 Excel

#### 2.2.3 数据保护
- 软删除机制（deletedAt 字段）
- 学生/家长只能查看自己的数据（ownershipMiddleware）
- 手机号非管理员角色中间 4 位打星号

### 2.3 教师管理 (P1)

- 教师 CRUD：姓名、工号、职称、科目、手机号
- 关联 User 表，自动创建登录账号
- 支持重置密码
- 可设为班主任（关联班级）

### 2.4 班级管理 (P0)

- 班级 CRUD：名称、年级（7/8/9）、学年、班主任
- 学生分班/转班
- 班级学生列表查询
- 班级统计（人数、成绩概况）

### 2.5 课程与课表 (P1)

#### 2.5.1 课程管理
- 课程 CRUD：名称、代码、年级、授课教师、周课时、学期
- 按年级 + 学期筛选

#### 2.5.2 课表管理
- 按班级设置周课表（每天 10 节课）
- 批量设置课表条目
- 按班级/教师视角查询课表
- 课表冲突检测（同班同时段唯一约束）

### 2.6 成绩管理 (P0)

#### 2.6.1 考试管理
- 考试类型 CRUD：月考/期中/期末 + 自定义名称
- 设置考试日期、权重
- 按学期 + 学年组织

#### 2.6.2 成绩录入
- 批量录入：选择考试 → 选择课程 → 选择班级 → 表格录入成绩
- 支持逐学生录入
- 自动校验分数范围

#### 2.6.3 成绩发布与统计
- **发布流程**：计算班级排名 + 年级排名 → 标记 isPublished
- **统计指标**：平均分、最高分、最低分、及格率、优秀率、分数段分布
- **撤回发布**：删除排名数据，恢复未发布状态
- 学生/家长端：查看已发布的个人成绩

### 2.7 考勤管理 (P0)

#### 2.7.1 考勤记录
- 批量标记：选择日期 → 选择班级 → 逐学生标记状态
- 状态类型：出勤/缺勤/迟到/早退/病假/事假
- 时段：上午/下午/全天
- 按日期 + 班级查询

#### 2.7.2 考勤统计
- 按时间段统计出勤率
- 按班级统计
- 缺勤趋势分析

#### 2.7.3 请假管理
- 学生/家长端提交请假申请：起止日期、类型、原因、附件
- 教师/管理员审批：同意/拒绝 + 审批意见
- 审批通过后自动同步考勤记录

### 2.8 费用管理 (P1)

#### 2.8.1 费用项目管理
- 费用项目 CRUD：名称、金额、类型（学费/杂费/住宿费/餐费/其他）
- 适用年级、学期、截止日期
- 一键生成全年级学生缴费记录

#### 2.8.2 缴费管理
- 查看缴费状态：未缴/部分缴/已缴/免缴
- 手动标记已缴费（线下收款场景）
- 学生/家长端：查看自己的缴费清单和状态
- 缴费状态统计和筛选

### 2.9 通知公告 (P0)

- 通知 CRUD：标题、内容（纯文本）、分类、目标范围
- 目标范围：全部/按年级/按班级/指定学生
- 置顶功能
- 发布/撤回机制
- 移动端通知列表 + 详情查看

### 2.10 宿舍管理 (P2)

- 宿舍楼管理：名称、类型（男/女）、楼层数
- 房间管理：房间号、所属楼栋、容量
- 学生分配：级联选择（班级 → 学生）→ 分配至房间
- 容量校验：分配时检查房间余量
- 移出学生
- 学生/家长端：查看宿舍信息

### 2.11 奖惩记录 (P1)

- 奖惩记录 CRUD：选择学生、类型（奖励/惩罚）、类别、描述、日期
- 按学生查询历史记录
- 学生/家长端：查看个人奖惩记录

### 2.12 数据看板 (P1)

- 核心数字卡片：学生总数、教师总数、班级数、今日出勤率
- 各年级人数分布
- 最近考试成绩概览
- 各年级成绩统计（平均分/及格率/优秀率）

## 3. 非功能需求

### 3.1 性能要求

| 指标 | 目标值 |
|------|--------|
| API 响应时间 (P95) | < 500ms |
| 页面首屏加载 | < 2s |
| 批量导入 (500 条) | < 30s |
| 并发用户数 | 100 |

### 3.2 安全性

- JWT Token 认证，accessToken 2h 过期
- 密码 bcrypt 加盐哈希
- 身份证号 AES-256 加密存储
- API 基于角色的访问控制 (RBAC)
- 数据所有权过滤（学生只能看自己的数据）
- 敏感操作记录审计日志

### 3.3 可用性

- PM2 Cluster 模式多进程
- 进程崩溃自动重启
- 数据库连接池管理
- 优雅的错误处理和用户提示

### 3.4 可维护性

- Monorepo 共享类型定义
- Zod 统一的输入校验
- 分层架构（Route → Controller → Service → Repository）
- 全局错误处理中间件

### 3.5 兼容性

- Web 管理后台：Chrome 90+, Edge 90+, Safari 15+
- 微信小程序：基础库 2.25+
