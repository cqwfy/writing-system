# 中学学生管理系统 — 用户使用手册

## 1. 系统登录

### 1.1 Web 管理后台登录（管理员/教师）

1. 在浏览器打开系统地址（如 `http://8.160.165.176`）
2. 输入用户名和密码
3. 点击"登录"按钮

**默认账号**（种子数据）:

| 角色 | 用户名 | 密码 |
|------|--------|------|
| 管理员 | admin | Admin@123 |
| 教师 | teacher1 | Teacher@123 |
| 教师 | teacher2 | Teacher@123 |
| 教师 | teacher3 | Teacher@123 |

> 首次登录后请立即修改密码。

### 1.2 微信小程序登录（学生/家长）

1. 打开微信小程序（需先通过审核或开发版预览）
2. 点击"微信一键登录"按钮
3. **首次登录**：需要绑定账号
   - 选择绑定方式（学号或手机号）
   - 输入对应的学号或手机号
   - 点击"绑定"
4. **已绑定用户**：自动登录进入首页

**默认账号**（种子数据）:

| 角色 | 用户名 | 密码 |
|------|--------|------|
| 学生 | student1 ~ student10 | Student@123 |
| 家长 | parent_f_20260001 等 | Parent@123 |

## 2. Web 管理后台操作指南

### 2.1 首页看板

登录后默认进入看板页面，显示：
- 核心数据：学生总数、教师总数、班级数、今日出勤率
- 各年级成绩概况
- 最近考试成绩列表

### 2.2 学生管理

**查看学生列表**：
- 左侧菜单 → "学生管理"
- 支持搜索（姓名/学号）、筛选（年级/班级/状态）

**新增学生**：
1. 点击"新增学生"按钮
2. 填写学生信息（学号、姓名、性别、班级为必填）
3. 可上传学生照片
4. 点击"确定"提交

**批量导入**：
1. 点击"导入 Excel"按钮
2. 下载模板文件
3. 按模板格式填写学生数据
4. 上传填写好的 Excel 文件
5. 系统自动校验并导入，返回成功/失败明细

**修改学生信息**：
- 在列表中点击"编辑"按钮，修改后保存

**删除学生**：
- 在列表中点击"删除"按钮（软删除，可恢复）

### 2.3 教师管理

- 管理员可查看、新增、编辑、删除教师
- 创建教师时自动生成登录账号
- 支持重置教师密码

### 2.4 班级管理

- 查看班级列表，按年级筛选
- 创建新班级，设置年级、学年
- 设置/更换班主任
- 查看班级学生名单

### 2.5 课程与课表

**课程管理**：
- 创建课程（名称、代码、年级、授课教师、周课时）
- 按年级和学期筛选

**课表管理**：
- 选择班级 → 查看周课表（7 天 × 10 节课）
- 批量设置课表条目（星期、节次、课程、教室）

### 2.6 成绩管理

**创建考试**：
1. 进入"成绩管理"页面 → "考试管理" Tab
2. 点击"新增考试"
3. 填写考试名称（月考/期中/期末）、考试日期、权重
4. 点击保存

**录入成绩**：
1. 切换到"成绩录入" Tab
2. 选择考试 → 选择课程 → 选择班级
3. 表格中输入每位学生的分数
4. 点击"批量保存"

**发布成绩**：
1. 录入完成后，点击"发布成绩"按钮
2. 系统自动计算班级排名和年级排名
3. 发布后学生端即可查看

**查看统计**：
1. 切换到"成绩统计" Tab
2. 选择考试
3. 查看各科平均分、及格率、优秀率、分数段分布

### 2.7 考勤管理

**日常考勤标记**：
1. 进入"考勤管理"页面 → "考勤记录" Tab
2. 选择日期和班级
3. 为每位学生选择考勤状态（出勤/缺勤/迟到/早退/病假/事假）
4. 点击"批量保存"

**请假审批**：
1. 切换到"请假审批" Tab
2. 查看待审批的请假申请
3. 点击"同意"或"拒绝"
4. 填写审批意见
5. 同意后系统自动生成对应的考勤记录

### 2.8 费用管理

**创建费用项目**：
1. 进入"费用管理"页面
2. 点击"新增费用项目"
3. 填写项目名称、金额、类型、适用年级、截止日期
4. 保存后，点击"生成缴费记录"为全年级学生批量创建

**查看缴费状态**：
- 在缴费记录表格中查看每位学生的缴费状态
- 支持按状态（未缴/部分缴/已缴/免缴）筛选

**标记已缴费**：
- 学生线下交费后，管理员点击"标记已缴费"按钮确认

### 2.9 通知公告

**发布通知**：
1. 进入"通知公告"页面
2. 点击"发布通知"
3. 填写标题和内容
4. 选择目标范围（所有人/按年级/按班级/指定个人）
5. 可设置"置顶"
6. 点击"发布"

**管理通知**：
- 编辑已发布的通知内容
- 撤回通知
- 删除通知

### 2.10 宿舍管理

**宿舍楼管理**：
- "宿舍楼栋" Tab：新增/查看宿舍楼（名称、类型男/女、楼层数）

**房间管理**：
- "宿舍房间" Tab：新增/查看房间（房间号、所属楼栋、容量）

**分配学生**：
1. 在房间列表中点击"分配学生"
2. 点击"+ 添加学生"
3. 选择班级 → 选择学生（级联选择）
4. 可添加多名学生
5. 系统自动校验房间容量
6. 点击确定完成分配

**移出学生**：
- 点击学生旁边的"移除"按钮

### 2.11 奖惩记录

- 进入"奖惩记录"页面
- 搜索选择学生（按姓名或学号）
- 选择类型（奖励/惩罚）、填写类别、描述、日期
- 保存记录
- 可按类型和学生筛选查看

## 3. 微信小程序操作指南

### 3.1 首页

登录后进入首页，显示功能导航：
- 成绩查询
- 考勤记录
- 费用缴纳
- 通知公告
- 宿舍信息
- 个人中心

底部 Tab 栏：
- 首页 | 成绩 | 通知 | 我的

### 3.2 查成绩

1. 点击底部"成绩" Tab
2. 点击上方"选择考试"下拉框，选择要查看的考试
3. 查看各科成绩表格（课程/分数/班级排名/年级排名）

### 3.3 查看考勤

1. 点击首页"考勤记录"或通过成绩页面切换
2. "考勤记录" Tab：查看每日考勤状态
3. "请假申请" Tab：提交新的请假申请

**提交请假申请**：
1. 切换到"请假申请" Tab
2. 选择起止日期
3. 选择请假类型（病假/事假/其他）
4. 填写请假原因
5. 点击"提交申请"
6. 等待教师审批

### 3.4 费用查询

1. 点击首页"费用缴纳"
2. 查看各项费用及缴费状态
3. 顶部显示待缴总额

### 3.5 查看通知

1. 点击底部"通知" Tab
2. 浏览通知列表
3. 点击任意通知查看详情

### 3.6 宿舍信息

- 点击首页"宿舍信息"
- 查看所在宿舍楼、房间号、室友信息

### 3.7 个人中心

1. 点击底部"我的" Tab
2. 查看个人信息（姓名、学号、班级等）
3. 点击"退出登录"可切换账号

## 4. 角色权限速查

### 4.1 管理员 (admin)

- 拥有系统全部权限
- 可管理所有数据
- Web 管理后台所有菜单可见

### 4.2 教师 (teacher)

- 可查看和管理学生信息
- 可录入和发布成绩
- 可标记考勤和审批请假
- 可发布通知
- 不可删除学生、不可管理教师、不可管理费用

### 4.3 学生 (student)

- 微信小程序端使用
- 查看自己的成绩（仅已发布）
- 查看自己的考勤记录
- 提交请假申请
- 查看缴费状态
- 查看宿舍信息
- 查看通知公告

### 4.4 家长 (parent)

- 微信小程序端使用
- 查看关联学生的成绩、考勤
- 为孩子提交请假申请
- 查看缴费状态
- 查看通知公告

## 5. 常见问题

### Q1: 忘记密码怎么办？
联系管理员重置密码。管理员可在"教师管理"中点击"重置密码"。

### Q2: 微信登录提示"绑定失败"？
请确认输入的学号或手机号是否正确。如仍有问题，联系班主任确认信息。

### Q3: 成绩看不到？
成绩需要教师"发布"后才能查看。如教师已发布但仍看不到，请确认是否选择了正确的考试。

### Q4: 请假申请提交后没有响应？
请假需要教师审批。提交后请耐心等待，或直接联系班主任。

### Q5: 小程序提示"request:fail url not in domain list"？
这是域名未配置的问题，请联系技术人员将服务器域名添加到微信小程序后台的合法域名列表。

### Q6: 如何修改个人信息？
学生/家长暂不支持自行修改信息，需要联系班主任在后台更新。
