# 浏览器战争史

**收集时间**：2026-05-07
**下次更新建议**：不需要定期更新（历史数据）

## 关键事实

### 第一次浏览器大战（1995-2001）
- 1995年中：Netscape Navigator 占 ~80%
- 1995.08：微软发布 IE 1.0，随 Windows 95 Plus! 捆绑
- 1997.10：IE 4.0 发布，IE 升至 ~60%
- 1998：Netscape 以 42亿美元卖给 AOL；代码开源，成立 Mozilla 项目
- 2001-2003：IE 巅峰 ~95-96%

### 第二次浏览器大战（2004-2012）
- 2004.11.09：Firefox 1.0 发布
- 2008.09.01：Google Chrome 发布（WebKit + V8）
- 2009.11：Firefox 巅峰 ~32%，IE 降至 ~56%
- 2011.12：Chrome 超越 Firefox
- 2012.05：Chrome 超越 IE，成为全球第一（~32%）

### Chromium 时代（2013-至今）
- 2013：Opera 放弃 Presto 引擎，转向 Chromium
- 2020.01：Edge 切换至 Chromium 内核
- 2025：Chrome ~71%，Safari ~15%，Edge ~5%，Firefox ~2%

### 核心规律
1. 每次浏览器权力转移都由"架构级创新"驱动（非功能叠加）
2. 垄断者的衰落总是从"创新停滞"开始
3. 平台绑定（Windows+IE）是最强的武器，但也可能是最脆弱的铠甲
4. 开源/开放标准在每一次战争中都是挑战者的武器
5. 新浏览器从不靠"更好用的浏览器"打赢——而是靠"重新定义浏览器"
