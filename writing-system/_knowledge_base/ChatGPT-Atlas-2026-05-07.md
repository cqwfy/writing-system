# OpenAI ChatGPT Atlas 浏览器

**收集时间**：2026-05-07
**下次更新建议**：Windows 版本发布时

## 关键事实

### 产品信息
- 发布时间：2025 年 10 月 21 日
- 平台：macOS（M系列芯片），Windows/iOS/Android "即将推出"
- 技术基础：Chromium + OWL（OpenAI Web Layer）架构
- 定价：基础免费，Agent 模式需 Plus（$20/月）或 Pro（$200/月）
- 基于 Chromium 内核，但 UI 层用 SwiftUI + AppKit 原生构建

### 核心功能
- 搜索反转：地址栏直接返回 AI 生成的整合回答，而非传统链接列表
- 上下文侧边栏：浏览任何网页时侧边栏 AI 待命
- 光标聊天：选中文本即呼出 ChatGPT
- 浏览器记忆：可选功能，记住浏览历史和偏好
- Agent 模式：AI 自主操控浏览器完成多步骤任务（仅付费用户）

### 市场数据
- Chrome 全球市场份额约 72%（2025年9月，StatCounter）
- Chrome 约 35 亿用户
- ChatGPT 超 8 亿周活跃用户
- 发布当日 Alphabet 股价下跌约 2.4%

### 最新动态（2026年）
- 2026年1月21日：Build 1.2026.15.3 更新（标签页分组、自动搜索切换）
- 2026年3月：宣布 Atlas 将与 ChatGPT 和 Codex 合并为桌面超级应用
- macOS 独占已近 8 个月，Windows 版本无确切时间表

### 竞品
- Chrome + Gemini（全平台，免费）
- Edge + Copilot（全平台，免费）
- Perplexity Comet（全平台，免费/付费）
- Opera Neon（全平台，免费，MCP 连接器）

### 性能（macOS M2 基准测试）
- 启动时间：1.8秒（Chrome 1.2秒，慢50%）
- 页面加载：2.3秒（Chrome 1.9秒，慢21%）
- 内存占用（10标签页）：1.2GB（Chrome 0.9GB，高33%）
