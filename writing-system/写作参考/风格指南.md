# 风格指南

> 本文件定义你的写作风格。每次写作前 AI 会参考，每次写作后你会更新它。

---

## 一、语言定位

**一句话描述**：像和聪明的朋友聊天，不像在写论文或做汇报。

**核心调性**：
- 真实 > 完美（有瑕疵的真实感比完美的 AI 腔好一万倍）
- 观点 > 客观（读者想看的是你的判断，不是百科词条）
- 具体 > 抽象（"省了3小时" > "提升了效率"）
- 短句 > 长句（能拆就拆）

---

## 二、开头方式

**偏好**：
- [ ] 直接进入具体事件或问题（"XXX 发布了。" "我用了一周 XXX。"）
- [ ] 用一个反常识的观点开场
- [ ] 用一个真实的场景或吐槽开场
- [ ] 设问句开场（"你有没有遇到过这种情况：..."）

**避免**：
- [ ] "在当今时代..." / "随着...的发展..."
- [ ] "最近，XXX 引起了广泛关注..."
- [ ] 背景铺垫超过 3 句还不进入正题

---

## 三、结构偏好

**文章整体**：
- [ ] 先给结论，再展开（倒金字塔）
- [ ] 用案例/数据支撑观点，不用空话
- [ ] 每个大段落有一个明确的"这一个信息点"
- [ ] 段落之间有逻辑推进，不是罗列

**段落内部**：
- [ ] 小标题 + 展开（适合教程/评测类）
- [ ] 观点句 + 解释 + 案例（适合论述类）
- [ ] 场景描述 → 问题 → 分析 → 启示（适合叙事类）

---

## 四、语言特征（待写作积累后细化）

**句式**：
- [ ] 短句为主（15-25 字），偶尔长句调剂
- [ ] 多用主动句，少用被动句
- [ ] 设问反问穿插，增加对话感

**词汇**：
- [ ] 口语化：用"用了"不用"进行了使用"
- [ ] 具体化：用"省3小时"不用"显著提升效率"
- [ ] 中文优先：能用中文说的不要夹英文（除非是专有名词如 API、Prompt）
- [ ] 避免AI高频词：赋能、破圈、底层逻辑、闭环、倒逼、抓手...

**节奏**：
- [ ] 快慢交替：短句快速推进 → 长句停下来解释 → 短句继续
- [ ] 多分段：手机屏幕 3-5 行为宜

---

## 五、金句风格（待积累）

**目标**：每篇文章至少有一句"读者想划线转发"的话。

**偏好类型**：
- [ ] 反常识洞察
- [ ] 精妙比喻
- [ ] 极简真理

---

## 六、禁忌清单

以下内容永远不要出现：
- [ ] "在当今时代" / "综上所述" / "值得注意的是"
- [ ] "不仅...而且..." / "既...也..."（连续出现）
- [ ] 没有信息量的形容词堆砌（"强大的"、"卓越的"、"全面的"）
- [ ] 中立客观不表达观点（"可能"、"或许"连用三次以上）
- [ ] 编造的数据、案例、引用
- [ ] 没有来源的"有研究表明"
- [ ] "你怎么看？欢迎留言讨论"（套路结尾）
- [ ] emoji 过度使用（整篇不超过3个）
