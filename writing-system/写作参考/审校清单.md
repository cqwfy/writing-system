# 三遍审校清单

> 每次文章完成后，按以下清单逐项检查。

---

## 第一遍：内容审校（对错）

### 事实准确性
- [ ] 所有数字经过核实？（用户数、性能数据、价格、时间）
- [ ] 所有产品名称拼写正确？（大小写、品牌名、版本号）
- [ ] 所有时间准确？（发布时间、版本更新时间）
- [ ] 引用来源可追溯？（能找到原始出处）
- [ ] 没有"某数据表明"、"据研究显示"等无来源表述？

### 逻辑一致性
- [ ] 前后观点无矛盾？
- [ ] 因果关系成立？（不是因为A所以B，而是有具体的因果链）
- [ ] 论证链条完整？（观点 → 论据 → 案例，缺一不可）
- [ ] 没有偷换概念？（同一个词前后意思一致）

### 结构合理性
- [ ] 没有跑题段落？（与核心主题无关的内容删掉）
- [ ] 没有重复表述？（同样的意思说了两遍）
- [ ] 段落顺序合理？（读者能顺着逻辑走）
- [ ] 每个大段有明确的"信息点"？（读完这段读者知道了什么）

### 零编造
- [ ] 所有案例都是真实的？
- [ ] 所有数据都能找到来源？
- [ ] 没有"我朋友说"、"某大厂员工透露"等无法验证的引用？
- [ ] 没有为了文章好看而夸张或编造的细节？

---

## 第二遍：风格审校（像不像人）

### AI 味检测

**套话检查**（出现即删/改）：
- [ ] "在当今时代"、"随着...的发展"
- [ ] "综上所述"、"总而言之"、"总而言之"
- [ ] "值得注意的是"、"不可忽视的是"、"需要强调的是"
- [ ] "不仅...而且..."连续使用
- [ ] "既...也..."连续使用
- [ ] "一方面...另一方面..."

**假大空间汇检查**（替换为具体表达）：
- [ ] "显著提升" → 提升了多少？
- [ ] "充分利用" → 具体怎么用的？
- [ ] "有效促进" → 促进了什么？数据？
- [ ] "极大改善" → 改善了什么？程度？
- [ ] "深度整合" → 怎么整合的？

**书面腔检查**（改成口语）：
- [ ] "进行操作" → 直接用动词
- [ ] "进行处理" → 直接用动词
- [ ] "对其进行" → 直接说对什么
- [ ] "基于此" → "这样" / "于是"
- [ ] "从而" → "这样就能" / 直接省略

**态度缺失检查**（加入观点）：
- [ ] 有没有连续三段以上没有明确观点？
- [ ] 有没有"可能"、"或许"、"一定程度上"连用？
- [ ] 有没有看似客观实则逃避判断的表述？
- [ ] 读完这篇文章，读者知道"我"的真实想法吗？

### 改写检查

**对照以下改写示例检查全文**：

| ❌ AI 味 | ✅ 人味 |
|----------|--------|
| 在当今AI技术飞速发展的时代 | Claude Code出了 |
| 通过充分利用AI的强大能力 | 用好AI |
| 可以显著提升内容创作效率 | 写文章能快一倍 |
| 这一现象从某种程度上反映了 | 这说明什么？说明 |
| 为广大用户带来了全新的体验 | 用起来确实不一样 |

---

## 第三遍：细节打磨（好不好读）

### 句子长度
- [ ] 找出所有超过 30 字的长句 → 拆短
- [ ] 15-25 字是舒适区，但也要有变化
- [ ] 连续 3 句以上同样的长度 → 需要变化

### 段落长度
- [ ] 有没有超过 5 行的段落？（手机屏幕）
- [ ] 关键观点句是否单独成段？
- [ ] 段落开头是否有变化？（不要每段都是"首先"、"其次"、"此外"）

### 标点
- [ ] 有没有逗号连接超过 30 字的长句？
- [ ] 分号使用是否必要？（多数情况下可以拆成两个句号句）
- [ ] 感叹号是否过度使用？
- [ ] 引号中的内容是真实的引用还是"强调"？（后者慎用）

### 节奏
- [ ] 大声朗读全文，有没有卡住的地方？
- [ ] 有没有句子读起来喘不过气？
- [ ] 关键转折处节奏是否变化？
- [ ] 结尾是否利落？（不要拖沓，不要重复）

### 排版（公众号）
- [ ] 段落间有空行？
- [ ] 关键句适当加粗？（一屏不超过3处）
- [ ] 列表和引用块使用得当？
- [ ] 如果配图，图片位置是否合理？

---

## 快速自检口诀

> 一校事实二校味，三校节奏放声读。
>
> 数据有出处，观点有态度，句子能朗读，段落能呼吸。
